# 160. 相交链表

- 难度: 简单
- 链接: https://leetcode.cn/problems/intersection-of-two-linked-lists/

编辑对应语言的 solution 文件，然后:

```bash
../../ex run 160 -l py      # 运行样例 0
../../ex test 160 -l py     # 判题 (py/go/cpp/ts)
../../ex test 160 -l all    # 四语言全测
```

> 输入 [listA, listB, skipA, skipB]：判题器构造相交链表；输出相交节点值，不相交输出 null

用例数: 3
